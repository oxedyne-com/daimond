Synchronisation entre appareils

Daimond est local d’abord, si bien qu’un second appareil démarre vide. La synchronisation entre appareils transporte vos chats et les fichiers de votre espace de travail entre vos propres appareils sans que le serveur ne les lise jamais.

Ce qui voyage par la passerelle est un unique paquet chiffré dont seuls vos appareils détiennent la clé. La clé vient de votre phrase secrète et ne quitte jamais le navigateur : le serveur conserve donc le paquet et ne peut pas l’ouvrir. Rien de lisible ne passe d’un appareil à l’autre.

Associer un second appareil

Chaque appareil crée sa propre identité : saisir votre phrase secrète sur un nouvel appareil ouvre un compte distinct, vide, au lieu d’amener celui que vous avez déjà. Pour utiliser le compte que vous avez déjà, associez le nouvel appareil à ce compte. Trois étapes.

  1. Sur l’appareil que vous utilisez déjà, ouvrez la fenêtre d’association

    Cliquez sur le bouton Associer un autre appareil de la barre du haut. Il affiche un QR code et un code d’association à usage unique.

  2. Sur le nouvel appareil, scannez le QR code — ou tapez le code

    Pointez l’appareil photo du nouveau téléphone vers le QR code : Daimond s’ouvre et le code est rempli pour vous, il ne vous reste qu’à toucher Associer cet appareil. Pas d’appareil photo ? Ouvrez Daimond là-bas, choisissez Vous avez un code d’association ?, et saisissez le code. Le code affiché sert seulement à vérifier qu’il correspond à celui du premier appareil.

  3. Déverrouillez avec la même phrase secrète

    Le nouvel appareil détient maintenant votre compte. Déverrouillez-le avec la même phrase secrète que sur votre premier appareil — pas une nouvelle — et vos chats et vos fichiers apparaissent. Une clé d’accès pourra le déverrouiller plus vite ensuite, une fois que vous en aurez ajouté une là-bas.

La phrase secrète est la même partout, mais elle ne voyage pas seule. Un compte, une phrase secrète, sur chaque appareil que vous associez — et la phrase secrète ne déchiffre qu’une clé que l’appareil possède déjà, si bien qu’un navigateur jamais associé n’a rien à ouvrir. Si un appareil vous demande de créer une phrase secrète plutôt que d’en saisir une, il est sur le point d’ouvrir un nouveau compte, et l’associer est la seule chose qui ramènera l’ancien.

Ce qui voyage

Vos chats, vos Diamonds et le graphe où vous les avez disposés, votre courrier, les fichiers de votre espace de travail, les appareils du compte, et ce que vous avez mis en pause. Tout fichier voyage, quel qu’en soit le type : une photographie, un enregistrement, un PDF ou un tableur atteint vos autres appareils comme le fait du texte, jusqu’à un gigaoctet pour un fichier. La corbeille aussi : une suppression comme une restauration atteignent chaque appareil.

Ce qui se synchronise est aussi ce qui est gardé dans le stockage en ligne, si bien qu’un espace de travail peut être plus grand que l’appareil sur lequel vous le lisez. Un fichier qui n’est pas sur cet appareil figure quand même dans l’arborescence, marqué d’un nuage, et descend quand vous le demandez. L’Espace de travail expose les trois états dans lesquels un fichier peut se trouver, comment la place est libérée à mesure que le navigateur se remplit, et ce que coûte le stockage en ligne.

Ce que cela coûte

La synchronisation entre appareils fait partie de Pro, le déblocage unique, qui reste acheté une fois pour toutes comme le reste de Daimond. Sans Pro, un appareil travaille seul ; avec, vos appareils restent au même pas. Pro active aussi le stockage en ligne et l’e-mail. Les corps de fichiers plus volumineux que la synchronisation transporte sont gardés dans le stockage en ligne, payés avec des crédits, avec une franchise gratuite avant que quoi que ce soit ne soit compté.
