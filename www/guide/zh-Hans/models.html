模型和提供商

daimon 用一个模型来思考。带上你已经有的一把密钥，直接付钱给那家提供商；或者买额度，让 Daimond 替你跑模型。

你自己的密钥

打开侧栏底部的模型行。它列出你用到的每一家提供商的密钥，以及新工作从哪个模型开始。 + 添加提供商 ，不管提供商是哪一家，问的都是同样三个问题。

  1. 选一家提供商

    Anthropic、Fireworks AI、OpenRouter、Together AI、Groq 或 DeepInfra。 自定义 ，展开一个 基础 URL 框，给任何说同一套聊天 API 的服务用，包括你自己机器上的一个。

  2. 粘贴密钥

    它被你的密码短语包住存起来，只发给你选的那家提供商，不给任何其他人。它只会裹在加密的同步包裹里到达你的其他设备，而且到了那里依然是包着的。

  3. 给一个默认模型加星

    列出模型 ，在提供商提供目录的地方拉取目录，否则你自己输入模型 ID。加了星的那个，就是新聊天和 diamond 开始的地方。

你的消息此后直接去那家提供商，记在你自己的账户上。Daimond 不在这条路上，我们也不收你任何钱。

换一个模型

默认值只是一个起点。任何已连接的模型都可以在某场聊天的头部选择器里单独选用，默认值不受影响。一个 diamond 还可以带一个独立的 帮手模型 ，给它派发的智能体用，只对下一个被派发的生效，对已经在跑的不起作用。

如果一个模型没有公开上下文窗口，卡片上会写 此模型的上下文大小未知。 ，不做任何猜测。

选择由谁来服务

路由器把一个模型交给它中意的任何一家上游提供商，而它们的质量并不一样。在一个 OpenRouter 提供商下面，每一行模型都带一个 提供商 字段，占位符是 偏好, -避开, !.

  • 单写一个名字，表示偏好那家提供商。
  • 开头带一个 - ，表示避开那一家。
  • 单独一个 ! ，表示只要这些，拒绝任何后备。

比如 Novita, -DeepInfra ，表示偏好一家、避开另一家。这个字段在你离开时自动保存。目录还没拉取过的提供商，它的那些行会先收在一个 模型… 的展开里，这样已经设好的偏好仍然能找得到。

额度

额度替你跑模型，不需要密钥；它们也计量少数几件要离开浏览器的事：抓一个页面、邮件和跨设备同步的带宽，以及超出免费额度的云端存储。同步、邮件和云端存储本身由 Daimond Pro 开启，而计量用量不论有没有 Pro 都从额度里扣。

打开额度那一行，看你的余额和可以买的额度包。额度不是订阅，买到的一直是你的。付款在支付服务商自己的托管页面上完成，所以没有卡号会输进 Daimond。

测试还没开放的时候，带额度的新账户凭验证码发放。没有验证码，Daimond 也能配合你自己的提供商密钥使用。

自动充值

自动充值是一条常设指令：额度不够时就去买，好让一个长任务不会跑到一半就停。这是 Daimond 唯一可能在你不在场时向一张已保存的卡收费的地方，所以它特意写得明明白白。三个数字设定它。

  • 当余额低于 ，是触发一次充值的余额。
  • 每次买这么多 ，是一次充值加多少。
  • 每月绝不多花超过 ，是这个自然月的硬上限。这个数要仔细定。它和扣费走同一条代码路径来强制执行。

没有保存过卡，它就打不开——一个打开之后悄悄失败的开关，比一个禁用着并说明原因的开关更糟。
