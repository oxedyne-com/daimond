模型与额度

daimon 用一个模型来思考。你可以带上自己的提供商密钥，直接付钱给那家提供商；也可以买额度，让 Daimond 替你跑模型。这一页两条都讲，还讲怎么让额度不断档。

给 daimon 供能的两条路

带上你自己的密钥

把你已经有的模型提供商账户接进来。你的消息直接去那家提供商；Daimond 不在这条路上，我们也不收你任何钱。

买额度

没有提供商账户要管。Daimond 替你跑模型，从你买下的额度里扣。没有订阅：买到的一直是你的。

任意一条都足以开始。两条也可以都走 —— 日常干活用自己的密钥，不想管密钥的时候用额度。

连接一家提供商

打开 模型 行，它在左下角的管理面板里。你用到的每一家提供商在这里各有一把密钥，也列出新聊天从哪个模型开始。要添加一家，选择 + 添加提供商 ，然后回答同样的三个问题 —— 不管提供商是哪一家。

  1. 选一家提供商

    从列表里挑 —— Anthropic, Fireworks AI, OpenRouter, Together AI, Groq, DeepInfra，或者 自定义 用于任何别的、说同一套 chat-completions API 的服务。选了自定义，会露出一个 基础 URL 框，把 Daimond 指向那个服务。

  2. 粘贴你的 API 密钥

    把你提供商账户里的密钥粘进 API 密钥 框。它只存在这台设备上，用你的密码短语包住，也只发给你选的那家提供商。

  3. 给一个默认模型加星

    从列表里选一个 默认模型 （自定义提供商则打一个模型 ID）。新的聊天和 Diamond 都从这一个模型开始。然后选择 保存并开始.

一切都留在这台设备上。 你的密钥、聊天和文件只存在于这个浏览器里。什么都不会发给我们 —— 你添加的提供商密钥只跟那家提供商说话，不跟任何别人。

默认模型，以及给某一场聊天换一个

有一个模型是默认的，新的聊天和 Diamond 都从它开始。任何一个已连接的模型都可以只用于某一场聊天：用中间面板右上角、聊天头部里的那个选择器切换，默认设置不动。Diamond 还可以给它派出的工人单独指定一个模型。

购买额度

打开 额度 行，它在管理面板里。它显示你的余额，以及一组可以买的额度包。没有订阅：买到的一直是你的，除非你打开自动充值，否则不会再有任何扣费。

付款在支付服务商自己的托管页面上完成。卡号、有效期和安全码从来不会输进 Daimond，所以这里没有什么可泄露的。

自动充值

自动充值是一条常设指令：额度快用完时买入，好让一件长活不至于做到一半停下。这是 Daimond 唯一可能在你不在场时扣一张已保存的卡的地方，所以它被刻意做得直白。三个数字定下它，就在额度视图里额度包的下面：

  • 当余额低于 —— 触发一次充值的余额。
  • 每次买这么多 —— 一次充值加多少。
  • 每月最多花 —— 一个自然月里所有充值加起来的硬上限。这个数要仔细定。它是天花板，不是目标；它和扣费走同一条代码路径，所以什么都绕不过去。
没有保存过卡，自动充值就打不开 —— 一个打开之后悄悄失败的开关，比一个禁用着并说明原因的开关更糟。保存一张卡会跳转到支付服务商的托管页面；Daimond 从不看到卡的信息。
