Modelle & Guthaben

Ein Daimon denkt mit einem Modell. Sie können Ihren eigenen Anbieterschlüssel mitbringen und diesen Anbieter direkt bezahlen, oder Guthaben kaufen und Daimond ein Modell für Sie laufen lassen. Diese Seite behandelt beides und wie Sie Guthaben aufgefüllt halten.

Zwei Wege, einen Daimon anzutreiben

Eigenen Schlüssel mitbringen

Verbinden Sie ein Konto, das Sie bei einem Modellanbieter schon haben. Ihre Nachrichten gehen direkt an diesen Anbieter; Daimond liegt nicht dazwischen, und von uns wird nichts berechnet.

Guthaben kaufen

Kein Anbieterkonto zu verwalten. Daimond lässt das Modell für Sie laufen und zieht vom gekauften Guthaben ab. Kein Abonnement: Was Sie kaufen, bleibt Ihnen.

Eines von beiden genügt für den Anfang. Sie können auch beides tun — einen Schlüssel für die tägliche Arbeit verbinden und Guthaben für die Fälle bereithalten, in denen Sie lieber keinen verwalten wollen.

Einen Anbieter verbinden

Öffnen Sie die Zeile Modelle im Verwaltungsfeld unten links. Sie führt für jeden Anbieter, den Sie nutzen, einen Schlüssel auf und zeigt, mit welchem Modell neue Chats starten. Um einen hinzuzufügen, wählen Sie + Anbieter hinzufügen und beantworten Sie dieselben drei Fragen, wer der Anbieter auch sei.

  1. Einen Anbieter wählen

    Wählen Sie aus der Liste — Fireworks AI, OpenRouter, Together AI, Groq, DeepInfra, oder Eigener Anbieter für jeden anderen Dienst, der dieselbe Chat-Completions-API spricht. Wenn Sie „Eigener Anbieter“ wählen, erscheint ein Feld Basis-URL zum Eintragen der Adresse, unter der dieser Dienst erreichbar ist.

  2. Ihren API-Schlüssel einfügen

    Fügen Sie den Schlüssel aus Ihrem Anbieterkonto in das Feld API-Schlüssel ein. Er wird nur auf diesem Gerät gespeichert, unter Ihrer Passphrase verpackt, und nur an den Anbieter gesendet, den Sie gewählt haben.

  3. Ein Standardmodell mit einem Stern markieren

    Wählen Sie ein Standardmodell aus der Liste (oder tippen Sie eine Modell-ID für einen eigenen Anbieter ein). Das ist das eine Modell, mit dem neue Chats und Diamonds starten. Wählen Sie dann Speichern und starten.

Alles bleibt auf diesem Gerät. Ihre Schlüssel, Chats und Dateien liegen nur in diesem Browser. Nichts wird an uns gesendet — ein Anbieterschlüssel, den Sie hinzufügen, spricht mit diesem Anbieter und mit sonst niemandem.

Das Standardmodell, und für einen Chat ein anderes wählen

Ein Modell ist das Standardmodell, mit dem neue Chats und Diamonds beginnen. Für einen einzelnen Chat lässt sich jedes verbundene Modell wählen: Öffnen Sie einen Chat und nutzen Sie die Modellauswahl in seiner Kopfzeile (oben rechts im mittleren Bereich), um nur dieses Gespräch umzustellen, ohne den Standard zu ändern.

Guthaben kaufen

Öffnen Sie die Zeile Guthaben im Verwaltungsfeld. Sie zeigt Ihren Saldo und eine Reihe von Paketen zum Kauf. Es gibt kein Abonnement: Was Sie kaufen, bleibt Ihnen, und es wird nichts erneut abgebucht, außer Sie schalten die automatische Aufladung ein.

Die Zahlung wird auf der gehosteten Seite des Zahlungsanbieters abgewickelt. Weder Kartennummer noch Ablaufdatum noch Prüfziffer werden je in Daimond eingetippt, hier gibt es also nichts, was abfließen könnte.

Automatische Aufladung

Die automatische Aufladung ist ein Dauerauftrag, Ihr eigenes Guthaben nachzukaufen, wenn es zur Neige geht, damit ein langer Auftrag nicht auf halbem Weg stehen bleibt. Sie ist die einzige Stelle, an der Daimond eine gespeicherte Karte belasten darf, während Sie weg sind, deshalb ist sie bewusst ausdrücklich. Drei Zahlen stellen sie ein, unter den Paketen in der Guthaben-Ansicht:

  • Mindestsaldo — der Saldo, bei dem eine Aufladung auslöst.
  • So viel kaufen — wie viel eine Aufladung hinzufügt.
  • Pro Monat nie mehr ausgeben als — eine harte Obergrenze für alle Aufladungen in einem Kalendermonat. Das ist die Zahl, auf die es ankommt: eine Decke, kein Ziel, und sie wird auf demselben Codepfad durchgesetzt wie die Abbuchung, sie lässt sich also nicht umgehen.
Die automatische Aufladung lässt sich ohne gespeicherte Karte nicht einschalten — ein Bedienelement, das sich einschalten lässt und dann still versagt, wäre schlimmer als eines, das ausgegraut ist und sagt, warum. Eine Karte zu speichern führt auf die gehostete Seite des Zahlungsanbieters; Daimond sieht die Kartendaten nie.
