モデル & クレジット

daimon はモデルで考えます。ご自分のプロバイダーの鍵を持ち込んでそのプロバイダーに直接支払うことも、クレジットを買って Daimond にモデルを動かしてもらうこともできます。このページでは両方と、クレジットを切らさない方法を扱います。

daimon に力を与える二つの方法

自分の鍵を持ち込む

モデルプロバイダーですでに持っているアカウントをつなぎます。メッセージはそのプロバイダーへ直接行きます。Daimond は経路に入りませんし、こちらから請求するものもありません。

クレジットを買う

管理するプロバイダーのアカウントはありません。Daimond があなたの代わりにモデルを動かし、買ったクレジットから引きます。サブスクリプションはありません。買った分はそのまま残ります。

始めるにはどちらか一方で足ります。両方もできます — ふだんの仕事には鍵をつなぎ、鍵を管理したくないときのためにクレジットを持っておく、という具合です。

プロバイダーをつなぐ

モデル の行を管理パネル（左下）で開きます。使っているプロバイダーごとの鍵と、新しいチャットがどのモデルで始まるかが並びます。追加するには + プロバイダーを追加 を選び、同じ三つの問いに答えます。プロバイダーが誰であっても同じです。

  1. プロバイダーを選ぶ

    一覧から選びます： Anthropic, Fireworks AI, OpenRouter, Together AI, Groq, DeepInfra、または カスタム は、同じ chat-completions API を話すほかのサービス向けです。カスタムを選ぶと ベース URL の欄が出て、Daimond をそのサービスに向けられます。

  2. API キーを貼り付ける

    プロバイダーのアカウントの鍵を API キー の欄に貼り付けます。この端末にだけ、あなたのパスフレーズのもとで包んで保存され、送られるのは選んだプロバイダーだけです。

  3. 既定のモデルに星を付ける

    既定のモデル を一覧から選びます（カスタムのプロバイダーならモデル ID を打ちます）。新しいチャットと Diamond が始まるのは、この一つのモデルです。そのあと 保存して開始.

すべてこの端末に留まります。 鍵もチャットもファイルも、このブラウザの中だけにあります。こちらには何も送られません — 追加したプロバイダーの鍵が話す相手はそのプロバイダーだけで、ほかの誰でもありません。

既定のモデルと、チャットごとに別のモデルを選ぶこと

既定のモデルは一つで、新しいチャットと Diamond はそこから始まります。つないであるモデルなら、中央パネル右上のヘッダーにある選択欄から、そのチャットだけに選べます。既定はそのままです。Diamond には、送り出すワーカー用に別のモデルを与えることもできます。

クレジットを買う

クレジット の行を管理パネルで開きます。残高と、買えるパックの一覧が出ます。サブスクリプションはありません。買った分はそのまま残り、自動チャージをオンにしないかぎり、あらためて請求されることはありません。

支払いは決済プロバイダー自身のページで行われます。カード番号も、有効期限も、セキュリティコードも Daimond に打ち込むことはないので、ここに漏れるものはありません。

自動チャージ

自動チャージは、クレジットが少なくなったら買っておく、という常時の指示です。長い仕事が途中で止まりません。あなたが席にいないあいだに Daimond が保存したカードへ請求しうる唯一の場所なので、あえてはっきりさせてあります。設定する数字は三つ、クレジットの画面のパックの下にあります。

  • 残高がこれを下回ったら：チャージが起きる残高です。
  • 買う金額：一度のチャージで足す額です。
  • 1 か月に使う上限は：暦の 1 か月あたりのチャージ合計の上限です。ここは慎重に決めてください。目標ではなく天井で、請求と同じコードの道筋で効くので、迂回できるものはありません。
保存したカードがないと自動チャージはオンにできません — オンになったのに黙って失敗する操作は、使えないと理由を言う操作より悪いからです。カードの保存は決済プロバイダーのページへの転送で、Daimond がカードの情報を見ることはありません。
