チャット & Diamonds

チャットは daimon との会話です。Diamond は、ひとつの取り組みを長く保つ容器です — ある仕事について分かったことがそこに残り、次の作業はそこから始まります。このページでは、チャットの始め方と読み方、やり取りの操作、チャットを Diamond にたたみ込むこと、Diamond が働く作業領域、そしてたまっていく Diamonds の整理を扱います。

チャットを始める、チャットに戻る

新しいチャット を選びます。押すのは ＋ — 隣は チャット です。レールの上部にあります。中央パネル下部の入力欄に書き、送信は ➤。始めたチャットはすべて、レールの チャット の下に並びます。クリックすると中央に戻ります。新しいチャットは既定のモデルで始まります。そのチャットだけモデルを変えたいときは、ヘッダーにあるモデルの選択欄から変えられます。

回答が届いているあいだも入力を続けられます。そのとき送ったメッセージは失われるのではなく 待機中 になります。スレッドの下に破線の吹き出しとして現れ、回答が終わった瞬間に、それ自身のやり取りとして送られます。待機中の吹き出しをクリックすると、入力欄に戻して書き直せます。捨てるときは、その × を押します。回答を止めるために ■ を押すと、その後ろで待機していたものは未送信のままあなたに返されます — 止めるとは、止めるということです。

長い会話を読む

会話はすぐに伸びるので、チャットのヘッダーには読みやすさを保つための操作が並んでいます。中央パネルの右上にあります。

ステップ

ステップ ボタンは、スレッド内のツールのステップを表示または非表示にします — あなたのメッセージとその回答のあいだに、エージェントがした仕事です。隠せば会話だけを読めますし、表示すれば実際に何をしたのかが見えます。

たたむ

− ボタンはすべての回答をたたみ、あなたが尋ねたことだけを残します。長いスレッドをざっと見るいちばん早い方法であり、たたむやり取りを選び始める入口でもあります。

前のメッセージへ戻る

↑ ボタンは、最後に送ったメッセージに戻ります。もう一度押すと、その前のものへ順にさかのぼります。

いちばん下へ

↓ ボタンはチャットのいちばん下に戻り、さかのぼりを最初からにします — つまり次の ↑ は、途中から続けるのではなく、最後に送ったメッセージに行きます。

チャットを Diamond にたたみ込む

会話が何かを突き止めたら、たたみます。学んだことを残し、それを生んだやり取りは落とします。たたみ込む先が Diamond.

Diamond は二つの単位でできています。

  • たたみ込み は一つの改善です — 一歩の前進です。
  • 結晶 は、たたみ込みが積み上げてきたものです。仕事のかたち、順序どおりの手順、そして苦労して見つけた確認事項。Diamond とは、結晶と、それを生んだたたみ込みの連なりを合わせたものです。

やり取りを選んでたたむ

スレッドを −でたたみ、残す価値のあるやり取りを選びます。そのための操作がヘッダーに並びます。

  • すべて選択 — すべてのやり取りに印を付けます。
  • 選択を解除 — 選択を解除します。
  • 選択分をたたむ — 選んだやり取りを Diamond にたたみ込みます。

たたむのは、あなたが 採り入れた一歩であって、通りすがりの一言ではありません。たたみ込みが残すのは学んだことで、記録そのものではありません。

ひとりでに取り込まれるものはありません。 結晶が裏で育つことはありません。差し出されたやり取りを選ぶのはあなたで、たたみ込み自体も提案です — エージェントが結晶を書き直し、その結果をあなたに見せ、あなたが受け入れるか拒否します。結晶が変わるのは、あなたがそう言ったときだけです。

Diamond を扱う

Diamonds はレールでチャットの上に並びます。追加するときに押すのは ＋ — 隣は Diamonds。Diamond を選ぶと、中央のチャットがそのコマンド面に入れ替わります — 仕事を導き、さらなる改善をたたみ込む、簡潔な画面です。パネルがどちらの顔を見せているかは、読まなくても分かります。Diamond のときはパネルが名前の横に Daimond のマークを取り、角を四角にします。画面のほかのものはすべて角が丸いからです。もう一度チャットを選べば会話はすぐ戻ります。Daimond は会話を中心に作られていて、舞台が空になりそうなときはいつでもそこへ帰るからです。

Diamond がすること、しないこと

Diamond は保持しますが、実行はしません。結晶を走らせるものはありません。Diamond の裏にワークフローエンジンはなく、スケジュールするものもなく、ある Diamond を別の Diamond につなぐものもなく、発火を待つ保存されたジョブもありません。Diamond に戻っても動き出しはしませんし、放っておいても同じです — 休んでいる Diamond は、あなたが離れたときのままです。

つまり また手に取る とは、すでに学んだことをすべて手にしたまま、もう一度導くということです。主張はそれだけですが、聞こえるより価値があります。結晶は文章であり、文章こそモデルがいちばんよく読むものです。Diamond を扱うときは daimon に文脈として渡され、そこから送り出されるすべてのワーカーにも渡されます。一度突き止めたことが、打ち直さなくても — 打ち直すべきだと思い出さなくても — また仕事に届きます。

結晶とその履歴

結晶は実在のファイルです — crystal.md。作業領域の中の、その Diamond 自身のフォルダーにあります。ほかのファイルと同じように、開いて読み、自分で編集できます。

結晶に書き込むたびにバージョンが記録されるので、結晶には履歴があり、上書きされて消えるものはありません。履歴は新しい順にすべてのバージョンを並べ、それぞれ何がそれを生んだかを示します。

  • 表示 — そのバージョンを読みます。
  • 復元 — そのバージョンをもう一度現在のものにします。
  • 差分 — たたみ込みが取り込んだ生の入力、つまりエージェントが縮めるために与えられた材料を見ます。
復元しても失われません。 現在だった文章は先に履歴へ残るので、古いバージョンを復元しても履歴は置き換わらず、増えます — 意図しない復元も、それ自体を取り消せます。

成果物

Diamond は、その仕事が触れたものも記録します。作業のあいだに書かれたファイルと、開かれたページです。これを自分で記録する必要はありません。Daimond はエージェントが使うツールをすべて記録しているので、一覧は起きたことから読み取られます — 集められるのは、あなたがたたみ込みを受け入れた瞬間です。

ただ 読んだ だけのファイルは、意図的に外してあります。エージェントは一つを探して四十のファイルを開くかもしれず、四十すべてを並べれば大事な一つが埋もれます。残すのは仕事が生んだものと、あなたが見たいと言ったページです。

Diamond に成果物があるときは、導く欄の上の行がその数を伝えます。クリックすると一覧が開き、各項目は三つのことをします。

  • 名前 はそれを開きます — ファイルは文書パネルに、ページはウェブパネルに。
  • 小さな矢印 は、それへの参照を導く欄に置きます。パスを打たずに「これの数字をやり直して」と言えます。
  • ×印 は、やはりこの Diamond のものではなかったときに取り除きます。
その後に名前を変えたり削除したりしたファイルは、開こうとしたときに そう告げます — 黙って何もしないのではありません。切れたリンクをそうでないふりで並べる一覧は、一覧がないより悪いからです。

Diamond の作業領域

Diamond には 作業領域があります。Diamond とともに置いておく、あなたのファイルとフォルダーのことです。そこに置くのはあなたです — daimon は自分の作業領域に何かを足すことができないので、渡されたもので仕事をし、足りないときはあなたに尋ねます。

これはあなたのファイルの見え方であって、ファイルを入れておく箱ではありません。 Nothing is copied when you attach something: the file stays where it is and the Diamond points at it. Attach the same folder to two Diamonds and there is still one folder — an edit made through either is the file the other reads. Taking something out of a Diamond's workspace only detaches it; the file itself is untouched, and only a deliberate delete removes it. The word 作業領域 invites you to expect a copy, and there is none.

Diamond には自分だけのディレクトリもあります。つねに作業領域の中にあり、つねに書き込めるので、あなたがまだ何も添えていないうちから daimon には仕事をする場所があります — 結晶はそこにあります。フォルダーは、 編集ではなく参照のために添えることもできます。そうすると daimon は読めますが、書き込みはすべて拒まれます。そして 作業領域 パネルは、あなたのファイルすべてを見せるか、この Diamond が持つものだけを見せるか、目の前の仕事に合うほうを示します。

daimon が開けるもの

daimon が開けるのは、自分の Diamond の作業領域にあるファイルだけです。 その外にあるものは、読むことも書くこともできません — daimon にもできませんし、daimon が送り出すどのワーカーにもできません。これは、モデルが従うかもしれないし従わないかもしれない、プロンプトの中の指示ではありません。この確認はコンパイルされたコードの中、すべてのファイルツールが通る唯一の扉に置かれています。そのコードは公開されているバンドルに入っていて、そのバンドルは再現可能な形で作られています。ですからこれは、信じるほかない主張ではなく、あなたが確かめられる主張です。

何を守らないのかも、あわせて言っておきます。これが定めるのは daimon がどこまで届くかであって、読んだものがどこへ行き着くかではありません。daimon が開いたものは、そのやり取りの残りとともに、あなたのモデルプロバイダーへ送られます。そして、思い違いをしているエージェント、あるいは何かを吹き込まれたエージェントには効きます — 見知らぬ他人の指示を載せたウェブページやメールを読んだ直後に、その他人のために探しに出たやり取りであっても、この Diamond の作業領域の外へは何も届きません。守らないのは、あなたが送ったものを悪用するプロバイダーや、こちらが公開したものとは違うビルドです。それらに答えるのは ブラウザから出ていくもの と すべてのビルドの封印された記録であって、これではありません。

ワーカーを送り出す

作業のなかには、記録されるだけでなく実際にやってほしいものもあります。そういうときは、Diamond の daimon が ワーカーエージェントを送り出します。ワーカーはそれぞれ自分の文脈で、作業領域のファイルツールを持って動き、常設の指示とこの Diamond の結晶を渡されます。あなたの取り組みについてワーカーが知っているのはその結晶だけです — ワーカーにあなたの会話は見えないので、渡す作業には必要なことを残らず書く必要があります。

同時に動くワーカーは最大で 八 体で、残りは順番を待ちます。daimon はワーカーを送り出したところでそのやり取りを終えます。出力を受け取ることはありません。それぞれが要約を報告し、残す価値のあるものをあなたが手でたたみ込みます — 結晶に何を入れるかの選択が、それであなたのものであり続けます。動いている実行は、ドックの エージェント パネルに出ます。

エージェントを止める、停止する

エージェントパネルのヘッダーには、 すべての エージェントに一度に効く操作が三つあります。同じ三つは各タイルにも付いていて、ひとつだけに効かせることもできます。

  • 一時停止 ⏸ — 動いているものを止め、待ち行列も保留します。動いていたエージェントは作り出した分をそのまま持ち、待っていたものはそもそも始まりません。再開するまで新しいものは動きません。思ったより速くお金を使っているファンアウトのためのブレーキです。
  • 再開 ▶ — 一時停止中のエージェントを、止まったところからすべて続けます。やり直しではなく自分の仕事を引き継ぐので、一時停止で失うのは待ち時間だけです。
  • 停止 ✕ — エージェントをそのまま終わらせます。それぞれできたところまでを、停止したタイルとして残します。 消去 を押すと片づきます。これが即時のキルスイッチです。

各タイルには 動いている間の費用 も出ます — 終わってからではなく、トークンと金額がその場で積み上がっていくので、止めるかどうかを考えながら、そのエージェントが何を使っているかを見られます。ヘッダーの下の一行は、エージェントが何体 実行中, 一時停止中 と 待機中であるかを伝えます。ファンアウトの規模 — そして費用 — が一目で分かります。これらを合わせたものが暴走に対するあなたの守りです。Daimond が自分で取る手立ては 支出 のページにあります。

知っておくとよい制限が二つあります。ワーカーは別のワーカーを送り出せないので、委任は一段で止まります。そして導ける Diamond は一度に一つなので、あなたが見ていないあいだに別の Diamond が働き続けることはありません。

タグ

Diamonds はたまっていくので、タグを付けられます。タグはあなたが決める短い札です。編集画面は手始めに四つを提案します — person, project, topic と org — でも Daimond が分類を押しつけることはありません。仕事に合う言葉なら何でも打てます。

打った文字は整えられます。タグは小文字にされ、前後の空白が落とされ、重複が取り除かれます。ひとつの Diamond に付けられるタグは最大 8 個、それぞれの長さは最大 24 文字です。タグはほかのすべてと同じように、この端末の、その Diamond 自身のメタ情報に保存されます。

編集画面には二つの箱があります。上は この Diamond のタグ、下は すべてのタグ です。上の箱のチップにある × は、そのタグをこの Diamond から外して下のたまりに戻します。そこで一度クリックすれば元に戻ります。下の箱のチップにある × は別の行いです。タグそのものを、それが付いたすべての Diamond から削除します。こちらは先に確認し、いくつの Diamond が変わるかを伝えます。手始めの四つの提案に ×は付きません。いつでも差し出されるものだからです。

タグは何もしません。それがタグの要点です。 タグはあなたの整理のためだけのものです。モデルに送られることはなく、結晶に入ることもなく、どのエージェントの動きも変えません。Diamond に 急ぎ とタグを付けても、扱いは何も変わりません。

一覧の上には検索欄があり、Diamond の 名前 と、その タグに一致します。結晶の中までは検索しません。タグのチップをクリックすると一覧がそのタグで絞り込まれます。一覧は最後に触れた順に並ぶので、直前に作業していたものが上に来ます。
