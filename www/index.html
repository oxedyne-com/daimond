    Give Daimond a token and it can push work you have already committed. Without one it can still commit, but every push is refused and the work stays on this machine.

    Just the name, as in github.com — no https://, no port, no path. Only pushes to this host are authenticated; a repository anywhere else is refused rather than reached with your token.

    A token that may push is enough; it never needs anything more. Daimond pushes only, only fast-forward, and only to origin — force, delete, mirror and any other remote are refused whatever the token allows. Empty this box and save to remove it.

    The token is encrypted under your passphrase and kept in this browser; it is never shown again, never sent to us, and never given to a model. Without an account there is nothing to encrypt it with, so it is held for this tab only and you will be asked for it again after a reload.
